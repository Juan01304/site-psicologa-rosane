# Site Psicóloga Rosane

Site institucional responsivo para a Psicóloga Rosane, em Nova Iguaçu/RJ.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Recursos

- Layout responsivo para desktop, tablet e celular
- Menu mobile
- FAQ interativo
- Animações de entrada
- Botões de contato via WhatsApp
- Seções de atendimento, apresentação profissional, palestras e contato

## Identidade visual

- Fundo: `#F2E8D5`
- Cor principal: `#00B4D8`

## Arquivos principais

- `index.html`
- `style.css`
- `script.js`

Desenvolvido para uso institucional da Psicóloga Rosane.
